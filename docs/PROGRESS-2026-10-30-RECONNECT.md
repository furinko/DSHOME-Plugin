# 整窗断线恢复与保留现场导出

新增顶部「保留现场」入口，显式导出旧场景中的客户端内存文档、便笺、扩展模块托管状态与布局。导出不读取宿主文件，不重连旧服务，不携带网页 URL 或终端进程身份，不自动导入执行；未知保存结果仍标记 uncertain，下载不等于文件保存或进程终止。

`test/retained-drafts.mjs` 检查导出白名单；`p0/full-scenario.mjs` 在成员归属撤回时真实下载并比对未保存文本。对应构建与浏览器日志：`test-output/retained-drafts-browser-20261030.log`。

新增 `p0/reconnect-scenario.mjs`：
- 关闭隔离环境实际 WebSockets，并通过夹具连接生命周期产生新 generation；
- 原场景和脏草稿保留，新连接生成独立场景；
- 直接尝试旧文档保存被拒绝，宿主字节未变；
- 新现场没有自动打开旧文档、启动旧终端或重放命令。

完整整窗浏览器场景通过：`test-output/desktop-reconnect-20261030.log`。generation 来源与重连通知仍由测试夹具提供，不等于生产登录、远端切换和空闲过期验收。断线前测试终端已明确关闭，本轮不声称活跃终端断线后恢复验证完成。

已知剩余问题：最多八个保留场景，尚需安全显式释放旧场景的入口以免连续多代连接耗尽上限；不能未经确认清除草稿或假定旧终端已终止。其他剩余工作仍包括多文档/终端组合、完整交互及设计核对、发布与证据整理。未修改运行目录、未装载、未重启、未推送。
