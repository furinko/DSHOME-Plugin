# DSHOME 现代工作台改版验收

候选版本：`0.4.0-preview.1`。方向由用户选定：现代工作台，更轻盈、留白更多，兼顾日常使用。

本次已完成源码、构建、隔离浏览器交互和只读独立复核；随后经用户本次明确同意，已装载并完成列明流程的生产现场验收，见 [装载记录与热更新限制](PRODUCTION-MODERN-2026-10-31.md)。旧版本 `0.3.0-dual.1` 的生产验收见 [原记录](PRODUCTION-ACCEPTANCE-2026-10-31.md)，不把旧版验收计为本版生产验收。

## 改版范围

- 重新组织整窗模式切换、工作台标题、项目与连接状态、主操作、命令入口、模块工具栏、卡片分区和底部状态；浅色与深色沿用宿主主题，统一使用 SVG 图标。
- 文件标签显示宿主确认的文件名；自定义名称保留。待保存与未知保存结果分别提示，未知结果不会显示成“已保存”。网页标签显示站点主机名。
- Ctrl/⌘+P 快速打开文件，Ctrl/⌘+K 或 Ctrl/⌘+Shift+P 搜索命令；支持已有文件、路径读取、键盘选择、焦点约束、Esc 关闭与焦点恢复。读取失败后可直接修改路径；等待时也能关闭，取消后的迟到回执不分配文档或抢回焦点。终端保留 Ctrl+K/P 的 shell 按键，使用 Ctrl+Shift+P 打开命令。
- 文档增加可见行号、路径与保存状态、查找、引用、比较、导出和保存入口；行号仅渲染可见范围，滚动保持对齐。BOM/CRLF/中文与 emoji 的原始保存规则保留。
- 整窗操作区较窄时自动进入单模块浏览，可切换所有模块；加宽后恢复分区。缩放本身不写布局。文件打开、标签、模块添加、展开及聊天引用返回都同步显示目标模块。
- 重做文档、网页、终端的空状态及便笺；布局编辑采用模块库、布局草稿和属性三部分，保留拖放、控件停靠、标签合并、交换、撤销、重做、取消和应用。

原有内容仍保持同一个 React 父容器和实例键。切换分区、视图、布局和同工作区会话不会重新挂载正文、iframe 或 xterm；导航不会启动终端或重放命令。文件和终端权限仍由公开 SDK 与宿主控制。
