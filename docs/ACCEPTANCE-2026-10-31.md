# DSHOME 0.3.0-dual.1 完成与验收记录

本候选补齐现有整窗工作台的文档、文件树、布局管理、网页、终端、便笺及键盘交互。源码和隔离验收已完成；生产装载与装载后的现场验收须取得本次明确同意。本记录不把旧版已装载、隔离浏览器或代码审查算作新候选的生产通过。

## 本轮完成

- 文档支持 Ctrl/⌘+S 保存、Ctrl/⌘+F 字面量查找、大小写、前后匹配、Escape 返回编辑、行列显示、草稿导出与磁盘比较；保留 BOM、CRLF 与 Unicode。Host 返回的项目和真实路径统一正文身份，相对、绝对、别名及并发打开保留同一份草稿。
- 文件树支持展开、键盘导航、筛选已列出条目、清空、刷新、隐藏文件开关和按路径打开。目录请求随会话/接口变化撤回，不假装提供全盘搜索。
- 布局支持导入/导出、自定义预设、编辑/应用/取消、撤销/重做、拖动与控件停靠、交换、标签键盘导航、分割条键盘/指针调整、收起/展开和放大。导入只采用同项目布局，保留现有内容，不读文件、不执行命令。
- 布局存储配额失败给出可理解反馈，保留原记录及当前内容；损坏、备份、事务恢复与跨页冲突流程保留。
- 网页支持载入反馈、显式重新加载确认与浏览器打开入口。模式、预设、布局及同工作区会话切换保留未提交表单；明确关闭或刷新仍可能丢失网页内存。
- 服务暂停时可编辑和导出草稿，保存及终端输入停用；可重新接入文件接口，或在有效服务下显式新建现场。旧现场保留可导出，不转移旧权限或重放命令。
- 终端显示连接状态和所属会话限制，有明确启动、重试、确认关闭及未确认关闭恢复。便笺有导出和关闭保护。工具栏、空态、主题变量、窄屏区域与焦点反馈同步整理。
- 测试依赖现在可在全新目录引导，构建清除已过期的生成入口，安装 peer 范围保留 `>=0.2.1-rc.2`。

## 复现

在此仓库运行，`DSH_SDK_ROOT` 指向已存在的 DSH 安装根目录，不能指向其 `node_modules`。不通过本流程更新宿主：

```sh
npm ci
export DSH_SDK_ROOT=/path/to/existing/deepseek-harness
export WORKBENCH_BROWSER=/path/to/existing/chrome
npm run test:setup
npm run build
npm test
npm run test:foundations
npm run test:dual
npm run test:dual-browser
npm run test:workspace-service-rebind-native
npm run test:workspace-ui
npm run test:client-registry
```

人工隔离预览沿用相同 SDK 与有界临时文件根，不连接正在运行的 DSH。设置一个仓库外回执路径后运行，读取其中 `url`，结束时仅向该预览进程发 SIGINT；该命令不是生产部署：

```sh
WORKBENCH_REVIEW_INFO=/tmp/dshome-review.json node p0/browser.mjs
```

## 操作边界及待验事项

当前 DSHOME `0.3.0-dual.0-dev` 的既有装载不代表本候选已装载。不得自动停止、重启、重载或替换 DSH，切换 runtime，或修改已装载插件。用户批准后，才可备份当前安装字节，通过公共插件管理器更新本候选，再在实际运行 profile 验收，并记录独立装载回执；批准插件更新也不授予宿主升级或重启权限。

本轮没有 Windows/macOS/Electron 实机或 OS 原生 IME，历史 Windows EPERM 不算修好；生产认证、空闲过期与批准弹窗尚待在实际环境验收。工作区目录、导航、授权回答和连接代次通知含显式夹具。UI 挂接使用真实公开 SDK，文件和 PTY 为实际行为。

刷新、移除与代码热替换不是无损内容恢复。更新前需保存/导出文档及便笺、处理未知保存结果并关闭终端；布局不保存正文、URL、网页表单或进程。代码/表格专用编辑器、任意 OS 原生应用嵌入和 AI 自动执行是后续模块，不在本候选宣称已交付的五类内置模块范围内。
