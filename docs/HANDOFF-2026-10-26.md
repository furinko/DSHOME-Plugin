## 宿主接口：已知事实与未验项

| 层 | 一手源码观察 | 对实现的约束 |
|---|---|---|
| 外层布局 | `dsh-client-ui-layout/lib/client.js` 的 `computeColumns` 同时求导航、中心、右栏；右栏本体另外绝对定位 | 不能再只改外层grid造成空白；必须让栏宽/轨道/拖动手柄一致 |
| 原生右栏 | `dsh-client-ui-sidebar-right/lib/client.js` 的 `place` 将自动新分栏限制在两个dock pane；`TabSlot`通过occurrence、hookContext、signal与renderSlot派发内容 | 批准的四内容区不能假装由原生两栏自然实现；原生内容公开可复用消费口尚未验证，不能深层私有导入或搬动React拥有的DOM冒充稳定接线 |
| slot所有权 | `dsh-client-ui-renderer/lib/client.js` 的ctx级renderSlot仅允许root；子slot由注册组件的有界renderSlot面消费 | 不能假设任意组件可以调用原生子slot，也不能抢占已有slot所有权 |
| 文件读取 | `dsh-api-workspace-files/lib/index.js` 提供read/readBytes/stat/list/changes等只读操作；workspaceFileScope由Session header和sandboxPolicy根解析 | 原接口没有保存；需要新增真实受控保存能力，不得用假按钮/文本缓存冒充落盘 |
| 文件写入底座 | `dsh-fs-local/lib/index.js` 的writeText在目标锁中检查replaceIfVersion/createIfAbsent并原子写入；`dsh-fs-sandbox`还会检查每调用policy | 必须沿宿主FS、身份/工作区和期望版本接线；不能Node fs或shell旁路。不能把实例内锁夸大成所有外部编辑器参与的全系统CAS |
| 终端 | 终端UI以sidebarRight.openTabs调用webTerminals.retainTabs；关闭有原生closeHandler；TerminalBody mount依赖真实view模型 | 保留React组件不等于PTY存活；实例必须有真实持有链。布局切换应spawn/close均为0，关闭只走一次。包内TerminalBody异步chunk不是已验证的第三方公有导入契约 |
| 网页 | 已识别需要稳定iframe节点、父树、key和src；尚未完成真实网页接线验证 | 同URL或截图不能证明没重载；应测加载次数、内存nonce和未提交表单。保留跨域/嵌入限制，不承诺任意站点可嵌入或读取 |
