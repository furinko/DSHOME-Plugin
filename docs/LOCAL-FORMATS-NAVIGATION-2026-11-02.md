## 文件与文件夹

Windows 系统选择器不能混选文件/目录，按用户要求提供“添加本机文件”“添加本机文件夹”两个按钮。支持拖入文件或文件夹，继续按操作区/原生聊天区分流。

目录使用浏览器 DirectoryHandle，按展开动作列出元数据，点击文件才读取正文。最多 32 个根、每目录 1000 项、32 层；显示截断提示。支持筛选、隐藏项、刷新、移除根；移除不删除磁盘文件、不关闭已经打开的文档。真实句柄重复添加复用；句柄只在内存，不上传、不给 AI、不中转到 Host 任意路径接口。

不支持 DirectoryPicker 的客户端可用 webkitdirectory 文件夹选择；这是文件快照，最多 10000 项，没有原件写权限、不自动发现新增文件，空目录可能无法返回。旧式拖入 entry API 可按需列目录但没有写入句柄。权限拒绝或目录消失显示错误和重试。退出/刷新不承诺恢复句柄。

## 本机格式支持

| 类别 | 本轮能力与边界 |
| --- | --- |
| UTF-8 文本、代码、Markdown、CSV/TSV、JSON/YAML/XML、日志等 | 沿用文本编辑器与显式保存，2 MB 上限；HTML 作为文本，不执行 |
| UTF-16、GB18030、Big5 等 | 选择编码后只读查看，不猜测后覆盖原件 |
| PNG/JPEG/GIF/WebP/BMP/ICO/AVIF/SVG | 浏览器图片预览；SVG 只作为 img，不注入 DOM |
| PDF | 本机 blob 交给浏览器 PDF 载体；实际显示依赖客户端内置查看器，提供下载原件兜底 |
| MP3/WAV/OGG/FLAC/M4A、MP4/WebM/MOV | 本机音视频 controls，解码依赖浏览器编解码器；隐藏面板暂停播放 |
| DOCX | 只读正文段落内容；不还原完整排版、图片、页眉页脚 |
| XLSX | 只读工作表/单元格地址与原始值或缓存结果，30 表、每表 500 行/100 个已存储单元格；不重算公式，日期可能是序列值 |
| PPTX | 按 presentation 关系顺序预览前 200 张幻灯片的文字，不还原版式、图形和动画 |
| 旧 DOC/XLS/PPT、压缩包/程序等 | 明确提示不支持内置预览，原文件不变 |

Office 本地解析有文件、条目、XML 解压和总量限制，不提取到文件系统，不访问外部关系，不执行宏或公式，不渲染来源 HTML。未知/加密/损坏文件拒绝并保留原件。媒体限 100 MB，Office 压缩文件限 32 MB。没有新增 npm 依赖；布局客户端声明已有 SDK primitives 注入以复用 Logo。

这些新增预览用于用户选定的本机文件和文件夹；原 Host 工作区文件接口仍是其受权限约束的文本接口，没有扩展成全盘读写。旧本机保存的非原子 CAS 限制仍保留。

**用户要求的接近 Office 完整编辑尚未实现。** 本轮内容预览不是完整编辑器，也不是完整格式还原。所需本机文档服务及保存桥方案在 [Office 编辑方案](OFFICE-EDITOR-PLAN-2026-11-02.md)。用户对新增后台安装尚未作出知情同意，目前只解释了含义，没有安装。
