# 固定模式入口与条件品牌（2026-11-02）

## 本轮范围

用户要求统一切换按钮位置，按钮仅写“聊天”和“工作台”，进入工作台后用“鲸鱼工作台”替换品牌 DSHOME。本次仅修改隔离候选 DSHOME-whale-toolbar，分支 feat/fixed-mode-brand-20261102，基于 b7770f1。开始时实际部署仓库 DSHOME-Plugin/main 的源码也是 b7770f1，工作树干净；这不是已加载 GUI 的证明。本轮不装载、重启、推送或修改 profile/私人数据。

## 实现

- 模式按钮在根 Frame 中只有一份挂载，固定于右上方：右距 12px、顶部为原生 chrome clearance 加 12px。聊天、工作台、空白会话、窄窗聊天/操作区和全局页面不换父节点、不换位置；按钮宽度固定，不因选中字体而抖动。
- 原生会话工具栏与工作台标题栏在既有行内为该位置留空，不增加模式专行。窄列按容器宽度压缩自有侧栏工具，避免覆盖原生右侧栏入口；保留原生 Windows 标题栏占位与拖拽区域。
- 侧栏 Name 组件订阅当前 dualShellP0：聊天为 DSHOME，工作台为“鲸鱼工作台”，切回恢复。支持服务晚到/退出及原生侧栏名插槽重新挂载。工作台品牌不换行并隐藏原有版本徽章以免挤压；没有改插件包名、通知来源、内部模式标识或存储键。
- 侧栏收起为原生窄轨时不会挂载品牌文字，保留这种宿主行为；不额外制造一份品牌名。窄窗“右侧聊天/操作区”是不同用途的辅助入口，其可访问名称与“聊天”模式按钮区分。
