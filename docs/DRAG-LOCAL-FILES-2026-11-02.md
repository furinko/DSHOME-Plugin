# 直接停靠与本机文件 · 2026-11-02

独立候选DSHOME-drag-files-20261102，feat/drag-local-files-20261102，基于0d444a6。未部署、推送、升级DSH或修改生产profile、Mind与私人数据。

## 功能

- 直接拖动模块标题或标签到另一个面板，四边分屏、中央合并标签，显示落点预览。无需先进入布局编辑。仍使用原model.dock和同一内容容器，不重建文档、iframe或终端；保存布局仍需显式操作。布局版本变化会拒绝过期拖动，不采用外部伪造token。
- “本机文件”使用浏览器showOpenFilePicker，从用户选定位置打开UTF-8文本，不受当前Host工作区目录限制。没有该API时使用普通文件选择，打开只读来源的可编辑副本，明确提示导出保存。
- 文件拖到操作区后打开。getAsFileSystemHandle可用时保留所选文件句柄；仅有File对象时打开副本。目录、二进制、无效UTF-8和超过2MB文本不支持，不修改原件。
- 本机文件与Host文件身份分开，相同名称不合并；同一真实句柄重复打开复用草稿。本机句柄只在浏览器内存中，不发给Host或AI、不写布局存储。原工作区权限链不变。
- 有写入句柄时“保存”请求浏览器许可、比较内容摘要，写入前再次比较并写后读回。没有句柄时禁用原文件保存，提供导出草稿。BOM/CRLF保留；失败不伪称已保存。

## 明确边界

浏览器文件能力不等于任意路径静默访问。系统禁止的文件仍不可访问；宿主Electron是否支持选择器与写入许可必须实机验收。没有修改或绕过宿主sandbox。

本机写入不是Host提供的原子CAS：比较与写入间仍可能有外部程序竞争，不能承诺跨进程原子冲突保护。尝试exclusive writer并二次比较、写后核对，失败保留草稿；避免同时在多个应用编辑同一文件。

本机文件没有可靠的绝对路径，当前不提供原生文件引用链接；可以手动复制选区发送。快速打开的Host路径列表不混入本机句柄，避免把同名本机文件错误当作工作区路径。刷新/退出不承诺恢复本机句柄或未保存草稿。
